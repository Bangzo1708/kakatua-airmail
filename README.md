Kakatua Airmail: Coral Ring Run — a browser flight game where you pilot a cockatoo mail plane through glowing coral rings over a tropical sea, dodging storms and landing on island airstrips to deliver the mail. Pure static HTML/JS, no libraries, no network — just fly, ring, and land.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
